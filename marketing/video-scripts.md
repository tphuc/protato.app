## Production Notes for All Scripts

### Recommended Tools
- **Screen recording**: CleanShot X or macOS built-in QuickTime Player
- **Cursor effects**: CleanShot X cursor highlight (or hand cursor overlay for clarity)
- **Text overlays**: CapCut (mobile) or DaVinci Resolve (desktop)
- **Audio**: Epidemic Sound or Uppbeat for royalty-free music
- **Transitions**: CapCut has built-in wipe/zoom transitions that work well

### Aspect Ratio Notes
- TikTok / Reels / Shorts: 9:16 vertical (1080x1920)
- X/Twitter video: 16:9 or 1:1
- The recording window should be cropped to show just the canvas area, not the full Mac UI — keeps the focus on the mockup

### Thumbnail Strategy
- **Before/After** thumbnails consistently outperform text-only
- Use the actual Protato output as the thumbnail image
- Add a subtle arrow or "BEFORE → AFTER" text in the thumbnail
- Bright, saturated colors from the mesh gradients catch the scroll

### Posting Cadence
- Launch week: 1 video/day for 7 days (cover all features)
- Week 2-4: 3 videos/week (tip style, user showcases)
- Ongoing: 1-2 videos/week (feature spotlights, update highlights)
